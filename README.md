##  About the Project

**LUMIS Studio** is a fully responsive landing page built for a fictional creative & digital agency. The site showcases the studio's services, highlights key performance metrics, and includes a contact section — all wrapped in a sleek, modern UI.

---

##  Features

- **Hero Section** — Bold headline with clear call-to-action buttons
- **Services Showcase** — 6 core capabilities displayed with icons and descriptions:
  -  Lightning Speed — Sub-100ms optimized performance
  -  Fluid Design — Smooth, adaptive user interfaces
  -  Fort Knox Security — Enterprise-grade protection
  -  Real-Time Sync — Live data updates
  -  AI-Powered — Intelligent feature integration
  -  Global Scale — Built to handle worldwide traffic
- **Stats Section** — Key numbers: 4K+ projects, 98% client retention, 12 years in business, 3× avg ROI
- **Contact Form** — Clean form with name, email, service selection, budget, and message fields
- **Responsive Design** — Optimized for all screen sizes
